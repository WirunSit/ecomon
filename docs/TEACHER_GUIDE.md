# คู่มือครู EcoMon Quest (1 หน้า)

เกมทบทวนชีววิทยา ม.6 เรื่องระบบนิเวศและประชากร นักเรียนต้องตอบคำถามให้ถูกจึงโจมตีมอนสเตอร์ได้ ตอบผิดได้อ่านเฉลยทุกข้อ
**หน้าครู:** `https://<โดเมนของเกม>/teacher.html` (หรือกด "สำหรับครู →" ใต้ปุ่มเข้าเล่นในหน้าเกม)

## 1. สมัครบัญชีครู
แท็บ **สมัครบัญชีครู** → ชื่อผู้ใช้ (อังกฤษตัวเล็ก/ตัวเลข/`_ . -`) · รหัสผ่านอย่างน้อย 8 ตัว · ชื่อที่แสดง ·
**รหัสเชิญของโรงเรียน** (ขอจากผู้ดูแลระบบ) → ครั้งต่อไปใช้แท็บ **เข้าสู่ระบบ**

## 2. สร้างห้องเรียนและแจกรหัส
แถบซ้าย → พิมพ์ชื่อห้อง เช่น `ม.6/1` → **สร้างห้องเรียน** ได้ **รหัส 6 ตัว** (เช่น `UF9K6Z`) → ให้นักเรียนกรอกในหน้าเกม
- นักเรียนเข้าด้วย **รหัสห้องเรียน + ชื่อเล่น + PIN 4 หลัก** ไม่ต้องใช้อีเมล · ชื่อเล่นใหม่ = สร้างบัญชีใหม่ด้วย PIN ที่กรอกครั้งแรก
- บอกนักเรียนให้ **จำ PIN** (ใส่ผิด 5 ครั้งล็อก 5 นาที · ตอนนี้ครูยังรีเซ็ต PIN ให้ไม่ได้ ลืมแล้วต้องใช้ชื่อเล่นใหม่ ของเดิมจะหาย)
- ในเกมนักเรียนกด "จับคู่อัตโนมัติ" (ห้องละไม่เกิน 5 คน) หรือ "สร้างห้องใหม่" แล้วบอกรหัสห้องให้เพื่อนกลุ่มเดียวกัน
- ห้องเรียนที่ผู้ดูแลสร้างไว้ให้แล้ว → ช่อง **รหัสห้องเรียนที่มีอยู่** → **รับดูแล** (ได้เฉพาะห้องที่ยังไม่มีครู)

## 3. ตรวจคำถาม (ไม่บังคับ — เกมใช้คำถามได้ทันที)
คำถามที่มากับเกม 127 ข้อเป็น "ร่าง" (Claude เขียน) และ **เกมใช้ได้ทันทีโดยไม่ต้องรออนุมัติ** · ครูตรวจทีหลังได้ในแท็บ **คลังคำถาม**:
1. กรอง **หัวข้อ** ที่จะสอน แล้วอ่านโจทย์ **เฉลย คำอธิบาย คำใบ้** (คำใบ้ต้องไม่บอกคำตอบตรง ๆ)
2. ข้อที่ **ผิดหรือไม่อยากใช้ → ถอนออก** (เลิกใช้ในเกมทันที) · ข้อที่ตรวจแล้วถูกต้อง → **อนุมัติ** (ไว้จำว่าตรวจแล้ว)
3. ตรวจครบทั้งหน้าจอแล้วใช้ **อนุมัติร่างที่แสดงทั้งหมด** ได้ (เฉพาะข้อที่ตรงกับตัวกรองอยู่)

แต่ละข้อแสดงสถิติ "ตอบถูก x/y" — ข้อที่คนผิดเยอะผิดปกติอาจเฉลยผิดหรือโจทย์กำกวม ควรตรวจก่อน
(ถ้าโรงเรียนอยากใช้เฉพาะข้อที่ครูอนุมัติแล้ว ให้ผู้ดูแลระบบตั้ง `INCLUDE_DRAFT_QUESTIONS=0`)

## 4. นำเข้าคำถามของครูเองจาก CSV
แท็บ **คลังคำถาม** → **ดาวน์โหลดแม่แบบ CSV** → กรอกใน Google Sheets/Excel → ส่งออกเป็น CSV (UTF-8)
→ **เลือกไฟล์ CSV** (หรือวางข้อความ) → **ตรวจก่อน** (บอกแถวที่ผิดพร้อมสาเหตุ) → แก้จนผ่าน → **นำเข้า**

| คอลัมน์ | วิธีกรอก |
| --- | --- |
| `id` | ภาษาอังกฤษตัวเล็ก/ตัวเลข/`_` ไม่ซ้ำ เช่น `kru_food_01` · นำเข้า id เดิมซ้ำ = แก้ข้อเดิม (แก้ข้อที่มากับเกมไม่ได้) |
| `topic` | id หัวข้อ เช่น `food_chain`, `pop_growth` (ดูรายชื่อในตัวกรองหัวข้อ) |
| `difficulty` · `type` | ความยาก `1`–`3` · `mcq` ปรนัย / `truefalse` ถูก-ผิด / `numeric` ตัวเลข / `image_mcq` ปรนัยมีภาพ |
| `stem` · `choice_a`–`choice_d` | โจทย์ และตัวเลือก (ปรนัย) |
| `answer` | `a`–`d` · `true`/`false` · หรือตัวเลข (ใส่ `tolerance` ค่าคลาดเคลื่อน และ `unit` หน่วยได้) |
| `explanation` · `hint` | คำอธิบายที่นักเรียนเห็นหลังตอบ (ควรมีทุกข้อ) · คำใบ้ (ไม่บังคับ) |

ข้อที่นำเข้าเป็น **ร่าง** และใช้ในเกมได้ทันที (ถอนออกได้ถ้าต้องการ)

## 5. อ่านรายงาน (แท็บ ผลการเรียน)
- ตาราง **นักเรียน × หัวข้อ** เลือกแสดงได้ 2 แบบ: **% ตอบถูก** หรือ **ค่าความชำนาญ** (เริ่ม 50 ถูก +8 ผิด −6 ช่วง 0–100 —
  เกมใช้ค่านี้เลือกข้อยากขึ้น/ง่ายลง และถามหัวข้อที่อ่อนบ่อยขึ้น)
- สี **แดง = ยังไม่เข้าใจ → เขียว = เข้าใจดี** · ช่องเทา = ยังไม่เคยตอบ · ชี้ที่ช่องเพื่อดูจำนวนข้อที่ถูก/ทั้งหมด
- คอลัมน์ Lv. รวม และ "เข้าเล่นล่าสุด" ใช้ดูว่าใครยังไม่ได้เล่น
- **ข้อที่ผิดบ่อยที่สุด 10 ข้อ** ของห้อง → ใช้เลือกเรื่องที่ควรสอนซ้ำ/อธิบายเพิ่มในคาบ
- **ส่งออก CSV** เปิดใน Excel/Google Sheets ได้ · กด **รีเฟรช** เพื่อดูผลล่าสุดระหว่างคาบ

## 6. ตั้งค่าห้องเรียน (แท็บ ตั้งค่าห้องเรียน — แยกทีละห้อง แล้วกด บันทึก)
- **จับเวลาตอบคำถาม** — ปิด = โหมดฝึก นักเรียนคิดได้ไม่จำกัดเวลา (เหมาะกับห้องที่อ่านช้าหรือช่วงแรกของบทเรียน)
- **หัวข้อที่ใช้ถาม** — ติ๊กเฉพาะหัวข้อที่สอนถึงแล้ว · ไม่ติ๊กเลย = ทุกหัวข้อ
  (หัวข้อที่เลือกต้องมีคำถามที่ยังไม่ถูกถอนออก ไม่งั้นนักเรียนต่อสู้ไม่ได้)
- **จำนวนครั้งเข้าดันเจี้ยน** — เว้นว่าง = ค่าเริ่มต้นของเกม (1 ครั้งต่อ 60 นาที) · เพิ่มได้ถึง 20 เช่นคาบที่ให้เล่นดันเจี้ยนเป็นกลุ่ม

**แนะนำการใช้ในคาบ:** **เปิดหน้าเกมก่อนเริ่มคาบ 2–3 นาที** (server แผนฟรีหลับเมื่อไม่มีคนใช้ ปลุกครั้งแรก ~1 นาที) ·
ให้นักเรียนเข้าห้องเดียวกันเป็นกลุ่ม 3–5 คน · ดันเจี้ยนหนึ่งรอบใช้เวลาราว 5–8 นาที (เพื่อนที่ไม่กดอะไรเกิน 30 วินาทีถูกข้ามเทิร์น เกมไม่ค้าง) ·
ท้ายคาบเปิดรายงาน "ข้อที่ผิดบ่อย" แล้วเฉลยร่วมกัน · มีปัญหาเข้าไม่ได้ทั้งห้อง แจ้งผู้ดูแลระบบ (ดู `docs/DEPLOY.md`)
