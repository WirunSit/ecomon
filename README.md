# EcoMon Quest

เกมเว็บ MMORPG ล่ามอนสเตอร์สำหรับทบทวนชีววิทยา ม.6 หน่วยระบบนิเวศและประชากร
ต้องตอบคำถามให้ถูกจึงจะโจมตีได้ เล่นร่วมกันได้ห้องละไม่เกิน 5 คน

- แผนพัฒนาทั้งหมด: [`docs/GAME_PLAN.md`](docs/GAME_PLAN.md)
- กติกาโปรเจคสำหรับนักพัฒนาและ Claude: [`CLAUDE.md`](CLAUDE.md)

## เริ่มใช้งาน

ต้องมี Node.js 20 ขึ้นไป

```bash
npm install
npm run validate      # ตรวจไฟล์ content ทั้งหมด
npm run dev           # server http://localhost:2567 + client http://localhost:5173
```

เปิด http://localhost:5173 แล้วเข้าสู่ระบบด้วย **รหัสห้องเรียน `DEMO01`** (สร้างให้อัตโนมัติตอนพัฒนา) + ชื่อเล่น + PIN 4 หลัก
ชื่อเล่นใหม่ = สร้างบัญชีใหม่ด้วย PIN นั้น · ครั้งแรกจะให้เลือกมอนตั้งต้น 1 ใน 3 ตัว แล้วเลือกเข้าห้อง:

- **จับคู่อัตโนมัติ** เข้าห้องที่ยังไม่เต็มของห้องเรียนเดียวกัน
- **สร้างห้องใหม่** ได้รหัส 6 หลัก (มุมขวาบน) ให้เพื่อนพิมพ์เข้าห้องเดียวกัน · ห้องละไม่เกิน 5 คน

ลองเปิดหลายแท็บ (หรือหน้าต่างไม่ระบุตัวตน) ด้วยชื่อเล่นต่างกัน จะเห็นกันเดินในห้องเดียวกัน

**การต่อสู้:** เดินชนมอนป่าบนแผนที่ → เลือกท่า → ตอบคำถามให้ถูกจึงโจมตีโดน (ตอบไวภายใน 10 วินาทีแรงขึ้น)
หลังตอบทุกข้อจะเห็นเฉลยและคำอธิบาย · ชนะแล้วได้มอนตัวนั้นมาเป็นเพื่อน + EXP + เหรียญ
แพ้ไม่เสียอะไร กลับไปพักที่น้ำพุกลางหมู่บ้าน (เดินเข้าใกล้น้ำพุ มอนในทีมหายเหนื่อย)

| การควบคุม | |
| --- | --- |
| เดิน | ลูกศร หรือ W A S D · บนมือถือใช้จอยมุมซ้ายล่าง |
| เมนู | ปุ่ม "เมนู" มุมขวาบน หรือกด M / Esc (มีออกจากห้อง / ออกจากระบบ) |
| แชท | ปุ่ม "💬 แชท" เลือกข้อความสำเร็จรูปหรืออีโมต (พิมพ์เองไม่ได้ เพื่อความปลอดภัย) |
| ต่อสู้ | คลิกปุ่ม หรือกด 1–4 เลือกท่า/ตัวเลือก · Enter = ตอบ / ต่อไป |
| โหมดทดสอบ | แผงขวาบน (เปิดอัตโนมัติตอน `npm run dev` หรือใส่ `?dev=1`) ให้/เอาออก ห่วงยาง เรือ ไฟฉาย เพื่อทดสอบการลงน้ำ · เรียกมอนป่ามาข้างหน้าเพื่อทดสอบการต่อสู้ |

หน้าตรวจ content ของเฟส 0 (มอนสเตอร์ครบทุกร่าง) เปิดได้ที่ http://localhost:5173/?scene=preview

## Server และฐานข้อมูล

- ต้นแบบใช้ SQLite ที่ `server/data/ecomon.sqlite` (สร้างเองตอนเริ่ม) · ตัวแปร env ดู [`server/.env.example`](server/.env.example)
- สร้างห้องเรียนให้นักเรียน: `npm run create-class -w server -- ม6A1 "ม.6/1"` (รหัส A-Z0-9 4–8 ตัว)
- แก้ตารางใน `server/src/db/schema.ts` แล้วรัน `npm run db:generate -w server` เพื่อสร้างไฟล์ migration (รันเองตอน server เริ่ม)
- client หา server จาก `VITE_SERVER_URL` (http(s):// หรือ ws(s)://) ถ้าไม่ตั้ง ใช้พอร์ต 2567 ของเครื่องเดียวกัน

## คำสั่งอื่น

```bash
npm test              # unit test (vitest)
npm run typecheck     # ตรวจชนิดข้อมูล TypeScript ทุกส่วน
npm run placeholders  # วาดภาพ placeholder ใหม่ (ไม่เขียนทับภาพจริง)
npm run make-test-map # สร้างแผนที่ทดสอบใหม่ (ไม่เขียนทับ ถ้าแก้ใน Tiled แล้ว)
npm run assets        # ตัด sheet ภาพใน asset-src/ เป็นไฟล์แยก (ต้องมี Python: pip install -r tools/requirements.txt)
npm run build         # validate + build client สำหรับ deploy
```

## แก้แผนที่

เปิด `content/maps/test_island.tmj` ด้วย [Tiled](https://www.mapeditor.org/) ได้เลย กติกาเลเยอร์อยู่ใน [`CLAUDE.md`](CLAUDE.md)
บันทึกแล้วรัน `npm run render-maps` (วาดภาพพื้นใหม่ให้ขอบโค้งเป็นธรรมชาติ) และ `npm run validate` เพื่อตรวจ
ปรับหน้าตาพื้นแต่ละชนิด (ขนาดลาย ความนุ่มของขอบ ฟองคลื่นริมน้ำ) ได้ที่ `asset-src/terrain.yaml`

## เพิ่มมอนสเตอร์หรือคำถาม

ไม่ต้องแก้โค้ด ดูขั้นตอนในแผนหัวข้อ 12.3 (มอนสเตอร์) และ 12.4 (คำถาม) แล้วรัน `npm run validate`

คำถามใน `content/questions/` ที่ผู้เขียนเป็น "Claude (ร่างให้ครูตรวจ)" ยังเป็น `draft` ทั้งหมด **ครูต้องตรวจแล้วเปลี่ยนเป็น `approved`**
ก่อนใช้จริง (ตอนพัฒนา server ใช้ข้อ draft ด้วย แต่ตอน production ใช้เฉพาะ approved — ตั้งค่าได้ที่ `INCLUDE_DRAFT_QUESTIONS`)
ถ้าไฟล์ผิด ตัวตรวจจะบอกชื่อไฟล์ บรรทัด และสาเหตุ เช่น

```
✖ content/monsters/puibai.json:12 [baseStats.hp] — hp ต่างจากแม่แบบ tank +20 (เกิน ±10)
```
